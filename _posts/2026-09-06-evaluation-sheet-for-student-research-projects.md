The following is a checklist for student research projects, such as lab courses or
theses, which I as a course supervisor use for grading. The more checkmarks you
collect the better the grade, obviously. In order to achieve many checkmarks
"checked", you might want to refer to my other blog articles.

## Report Appearance

- ✅/❌ The report has been submitted on schedule.
- ✅/❌ The report is written about the proposed topic.
- ✅/❌ The report has the minimum required number of pages (excluding appendix and bibliography).
  - Master thesis: 60 pages (single column, [template link](https://sharelatex.tum.de/templates/tum-templates/tum-thesis-v2.0.0))
  - Bachelor thesis: 40 pages (single column, [template link](https://sharelatex.tum.de/templates/tum-templates/tum-thesis-v2.0.0))
  - Lab / IDP / guided research: 8 pages (double column, [template link](https://sharelatex.tum.de/templates/tum-templates/tum-article-v2.0.0))
- ✅/❌ The outline follows academic standards.
  - [How to Structure Student Theses and Reports](https://medium.com/@jhagerer/about-proper-outlines-for-student-reports-and-theses-15710154af7f)
- ✅/❌ The citation format is consistent and follows the provided recommendations.
  - [Dos and Don'ts for Student Theses (and Papers in General)](https://medium.com/@jhagerer/dos-and-donts-for-student-theses-and-papers-in-general-1b41fcf3ef10)
- ✅/❌ There are no two consecutive headings without text in between.
- ✅/❌ The abbreviations follow academic standards and best practices.
  - [Dos and Don'ts for Student Theses (and Papers in General)](https://medium.com/@jhagerer/dos-and-donts-for-student-theses-and-papers-in-general-1b41fcf3ef10)
- ✅/❌ There are no text formatting issues.
- ✅/❌ All tables and figures from the main text excluding the appendix are referenced.
- ✅/❌ All tables and figures contain meaningful content.
- ✅/❌ All tables and figures are marked as such and have captions below.
- ✅/❌ All tables and figures are readable.
- ✅/❌ All tables and figures are placed at the top of pages as far as feasible.
- ✅/❌ In case of a two-columnar layout: All tables and figures are placed symmetrical as far as feasible.
- ✅/❌ All figures are in vector format where possible.
- ✅/❌ All figures depicting scores which are not well-known should describe in the caption if higher or smaller is better.
- ✅/❌ All tables containing metrics should describe for each metric if higher is better, e.g. by using up-arrows for higher-is-better or down-arrows for lower-is-better.
- ✅/❌ In all diagrams, all axes are labeled and have units.
- ✅/❌ All diagrams and tables have a sufficient large font size for readability.
- ✅/❌ The amount of tables and figures do not hurt the readability of the actual text in the report.
- ✅/❌ Unnecessary tables and figures are moved to the appendix part behind the actual report and references. Tables and figures are unnecessary when they are redundant at least to some degree.
- ✅/❌ The spelling and grammatical errors are kept within reasonable limits.
- ✅/❌ Capitalization rules are applied correctly on normal text, i.e. only proper nouns are capitalized and technical terms are not capitalized.
- ✅/❌ Capitalization rules are applied correctly on titles, i.e., section and subsection headings, in accordance with the [Title Capitalization Tool](https://capitalizemytitle.com/).

## Report Content

This relates a lot to the standards defined here:
[How to Structure Student Theses and Reports](https://medium.com/@jhagerer/about-proper-outlines-for-student-reports-and-theses-15710154af7f)

- ✅/❌ The introduction introduces the topic for the informed non-expert reader.
- ✅/❌ The introduction motivates the topic, i.e., makes the reader curious.
- ✅/❌ The introduction formulates meaningful research questions.
- ✅/❌ The introduction contains an outline description.
- ✅/❌ The introduction contains a description of the contributions.
- ✅/❌ The related work section is comprehensive.
- ✅/❌ The related work section convincingly discovers research gaps.
- ✅/❌ The related work section is well structured.
- ✅/❌ The related work follows a golden thread.
- ✅/❌ The methodology section describes the methods to be evaluated.
- ✅/❌ The methodology section does not mention implementation details.
- ✅/❌ The data section describes the data distributions.
- ✅/❌ The data section describes the data generation process.
- ✅/❌ The report contains a pipeline/system overview diagram illustrating the data flow and experimental stages. It may be part of methodology, data, or experiments.
- ✅/❌ The experiments section contains the description of all experiments.
- ✅/❌ The experiments section contains all implementation details and parameters.
- ✅/❌ The experiments section describes which of the previously described data has been used.
- ✅/❌ The experiments section refers to the metrics used and why.
- ✅/❌ The results section shows results for all experiments.
- ✅/❌ The results section describes the results for all experiments.
- ✅/❌ The findings section answers all research questions sufficiently.
- ✅/❌ The findings section refers to the results.
- ✅/❌ The conclusion contains a summary of the findings section.
- ✅/❌ The conclusion contains a future work paragraph.
- ✅/❌ Each entry in the bibliography contains a URL to the publication.
- ✅/❌ Each entry in the bibliography follows the same format.
- ✅/❌ There is a section "AI Usage", see [How Should Students Document AI Usage in Academic Work?](https://dev.to/jhagerer/how-should-students-document-ai-usage-in-academic-work-58m1)

## Code Repository

- ✅/❌ A non-empty README.md file exists.
- ✅/❌ The README.md contains a short project description.
- ✅/❌ The README.md contains explanations about what is contained in the top-level directories.
- ✅/❌ The code project is structured reasonably well.
- ✅/❌ The README.md contains example code how to set up the project, collect the data, and run the experiments.
- ✅/❌ The project has some kind of standardized setup routines, e.g., at least a requirements.txt or a conda structure, but better something based on poetry or uv.
- ✅/❌ The example code actually works.
- ✅/❌ The experiments are reproducible.

## Poster (e.g. lab course)

- ✅/❌ The poster has been submitted on schedule.
- ✅/❌ The poster is written about the proposed topic.
- ✅/❌ The poster has been presented at the poster presentation.
- ✅/❌ The poster layout follows academic best practices.
- ✅/❌ The citation format follows academic best practices.
- ✅/❌ The abbreviations follow academic best practices.
- ✅/❌ All figures are in vector format where possible.
- ✅/❌ In all diagrams, all axes are labeled and have units.
- ✅/❌ The poster was readable from behind the desk.
- ✅/❌ The poster was high level enough.
- ✅/❌ The poster presentation convinced other supervisors that the students have full understanding of their own labor.
- ✅/❌ All questions from the supervisors could be answered in a sufficient manner.

## Defense Presentation (theses)

- ✅/❌ The defense presentation took place as planned.
- ✅/❌ The defense presentation was successful.
- ✅/❌ The duration of the defense presentation was correct (15 minutes presentation).
- ✅/❌ The slides were well prepared.
- ✅/❌ The slides were concise, not too full, and not too many.
- ✅/❌ The talk was well understandable.
- ✅/❌ The audience was engaged in discussions.
- ✅/❌ Backup slides existed.
- ✅/❌ All figures and tables had a caption.
- ✅/❌ All diagrams had the axes labeled properly.

## Effort

- ✅/❌ The proposed problem statement has been understood.
- ✅/❌ The proposed solution from the topic definition has been implemented as far as possible.
- ✅/❌ The proposed solution has been evaluated successfully.
- ✅/❌ An effort was made to ask questions and understand the problem.
- ✅/❌ New problems have been identified independently and proactively.
- ✅/❌ Innovative solutions have been found and proposed independently and proactively.
- ✅/❌ Innovative solutions have been implemented independently and proactively.
- ✅/❌ Innovative solutions have been evaluated successfully and proactively.
- ✅/❌ The student(s) kept surprising with own original ideas.
- ✅/❌ The student(s) has proudly achieved competence in the domain.
- ✅/❌ The student was able to identify with the topic.
- ✅/❌ If applicable: The student(s) were confronted with particular difficulties which is taken into consideration.

*The following points are only relevant for master thesis students:*

- ✅/❌ The insights generated by the student help the team moving forward.
- ✅/❌ The implementation from the student is either already integrated or provided such that it can and will be used by the team.
